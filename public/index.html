Capuz CMS API

An Open WebUI plugin that lets LLMs read, write, and publish .html and .xml pages on static sites — with draft preview before going live.

View on GitHub Built with daisyUI

What is this?

Capuz is a publishable MCP and OpenAPI tool server for hand-written HTML sites. Connect it to Open WebUI (or any MCP client) and describe page changes in plain language — the model edits drafts, you preview them, then publish when ready.

Storage backends include local filesystem, SFTP, Git (for Pages, Netlify, Vercel), and S3-compatible buckets. The API ships as a Docker image at ghcr.io/mauricewipf/capuz-cms-api.

How it works

1. Connect

Point Open WebUI at the MCP endpoint with bearer auth.

2. Edit drafts

The AI writes to drafts — preview on a separate host before publish.

3. Publish

Call publish_page to promote drafts to your live site.

MCP tools

Tool Description
list_pages List published pages
read_page / write_page Read or save a draft
publish_page Promote draft to live
delete_page Remove a page
